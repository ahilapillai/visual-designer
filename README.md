# ahila visual designer

Portfolio site for Ahila Pillai — graphic & visual designer and illustrator.

## Deploy on GitHub Pages

1. Create a repo named `ahila-visual-designer` under https://github.com/ahilapillai
2. Upload `index.html` (and this README) to the repo root.
3. Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Site goes live at https://ahilapillai.github.io/ahila-visual-designer/

`index.html` is fully self-contained — images, fonts and scripts are inlined, no build step.
